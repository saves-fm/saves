# @saves/tokens

Colors, type, spacing, radius and motion shared by the web and Flutter apps. The source is [`brand/tokens.json`](../../brand/tokens.json). In v0.2.0 a build step generates CSS variables for the web and a Dart theme for Flutter from it, and fails if any text or UI color falls below WCAG contrast (4.5:1 for text, 3:1 for UI).
